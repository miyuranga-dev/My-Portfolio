# Portfolio

A React + Vite portfolio site (plain JavaScript, no TypeScript).

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build for production

```bash
npm run build
npm run preview
```

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion (animations)
- Radix UI (tooltip, toast primitives)
- Lucide React + React Icons (icons)
- Wouter (lightweight routing)
